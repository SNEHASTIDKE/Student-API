# Student-API
Student Management System built using HTML, CSS, JavaScript, Spring Boot, and MySQL. Provides CRUD operations to add, view, update, and delete student records. Spring Boot handles REST APIs and backend logic, while MySQL manages data storage and JavaScript provides an interactive, responsive frontend.

# Student Frontend

A simple HTML/CSS/JS interface for the Student API.

## Requirements
- The backend (student-api) must be running on http://localhost:8080

## Setup
1. Open this folder in VS Code.
2. Right-click `index.html` → "Open with Live Server."
